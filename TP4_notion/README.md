# 📝 Projet To-Do List minimaliste

Ce projet est une application web minimaliste de gestion de tâches développée dans le cadre des travaux pratiques de Génie Logiciel. Il sert de support pour appliquer un workflow de développement intégrant Git (pour le contrôle de version) et Notion (pour la gestion de projet et le Kanban).

## ✨ Fonctionnalités principales
* **Ajouter une tâche** : Permet de saisir et d'enregistrer une nouvelle tâche.
* **Marquer une tâche comme terminée** : Permet de rayer une tâche accomplie.
* **Supprimer une tâche** : Permet de retirer définitivement une tâche de la liste.

## 🛠️ Technologies utilisées
* **Frontend** : HTML, CSS, JavaScript (Vanilla)
* **Gestion de version** : Git & GitHub
* **Gestion de projet** : Notion

## 🚀 Installation et exécution
1. Cloner le dépôt : `git clone TP4_notion`
2. Ouvrir le fichier `index.html` dans n'importe quel navigateur web.
